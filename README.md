# LinguaLink Lite

LinguaLink, öğrenilen dildeki bir metni ana dildeki çevirisiyle renkli ifade çiftleri hâlinde eşleştiren bir mobil dil öğrenme uygulamasıdır. Kullanıcı metni yapıştırır veya AI ile üretir, eşleşen ifadeleri görür ve dinler, sonra kaydettiği derslerle flashcard ve testlerle çalışır.
